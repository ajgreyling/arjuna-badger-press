## STAR GATE — how sessions work (in-world protocol)

1. **Target coordinate** sealed in double envelope; viewer blind.
2. **Cool-down** — breathing, sensory reduction (proto-Dispenza).
3. **Session** — sketch + verbal; monitor asks structured prompts.
4. **Feedback** — after the fact; viewers learn, bodies break.

**Fictional present-day wrinkle:** a **resonance target** — coordinates that only resolve when the
viewer's somatic state hits a profile stored in the door's geology.
