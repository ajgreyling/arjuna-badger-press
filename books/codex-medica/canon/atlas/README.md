# Southern African Useful Plants Atlas (living index)

Phase-1 machine-readable seed for Codex Medica Book XVI. Rows are **open-source starters**, not
transcriptions from van Wyk & Gericke. People's Plants supplies the *agenda* (20 use chapters) and
is cited as secondary literature; each taxon still needs a full intake card before monograph status.

## Files

| File | Role |
| --- | --- |
| `use-categories.json` | The 20 public use chapters (atlas agenda) |
| `taxa-seed.csv` | Starter taxa with use tags + caution bands |
| `../SOURCES_PEOPLES_PLANTS.md` | Cite-don't-copy doctrine |

## Caution bands

| Band | Meaning | Public detail |
| --- | --- | --- |
| `open` | Food/craft/low-hazard medicinal with broad public record | Identity + use class + plate OK |
| `caution` | Documented traditional use; safety, substitution, or claim-inflation risk | Identity + use class + plate; no prep/dose |
| `hold` | Intoxicant, abortifacient, sacred-restricted, or high-toxicity pathway | Metadata / name only until review |
