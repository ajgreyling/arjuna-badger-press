# Book VI :  Sources and Transmission

## 16. Source classes

| Class | Examples | Primary risk |
| --- | --- | --- |
| Living authority | Community custodian, practitioner, patient, harvester | Extraction, mistranslation, power imbalance |
| Field ethnography | Interview notes, recordings, participant observation | Recorder bias; frozen historical label |
| Classical materia medica | Dioscorides, Ayurveda, Chinese, Arabic-Persian, African manuscripts | Taxonomic ambiguity; copyist layers |
| Colonial record | Mission, military, settler and administrative texts | Racism, erasure, coercive collection |
| Archaeological | Residue, dental calculus, coprolite, vessel or pollen evidence | Use and indication inferred indirectly |
| Commercial | Labels, advertisements, formularies, trade catalogues | Marketing inflation |
| Biomedical | Case report, assay, animal model, trial, review | Preparation mismatch; publication bias |

## 17. Independence test

Ten websites quoting one ethnobotanical database equal one lineage, not ten confirmations. Every use report carries a transmission-parent field. Apparent cross-cultural convergence is counted only after likely copying, trade diffusion and shared textual ancestry are considered.

| Status | Criterion |
| --- | --- |
| Independent | No identifiable shared source or transmission route |
| Possibly independent | No citation link, but contact/diffusion plausible |
| Derived | Direct citation, translation, paraphrase or product-copy lineage |
| Unknown | Insufficient provenance |
