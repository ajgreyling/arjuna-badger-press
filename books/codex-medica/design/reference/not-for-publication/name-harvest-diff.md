# Name harvest vs taxa-seed (private)

Private design note. Not for publication. Does **not** merge harvest into `taxa-seed.csv`.

Sources:
- Harvest: `design/reference/not-for-publication/name-harvest-latin.txt`
- Seed: `canon/atlas/taxa-seed.csv` (`scientific_name`)

## Normalization

- Lowercase, collapse internal whitespace, strip.
- Match preference: **exact** normalized equality first.
- Then **containment** for infraspecific / longer forms: seed name token-prefix of harvest, or harvest token-prefix of seed (binomial+ only; avoids mid-string noise).
- **Genus-only** harvest names match only a genus-only seed of the same genus. A genus-only harvest does **not** count as covering all seed binomials in that genus, and a seed binomial does **not** count as matching a genus-only harvest.
