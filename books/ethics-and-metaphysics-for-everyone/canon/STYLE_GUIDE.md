# Style Guide — *Ethics and Metaphysics for Everyone*

> **Binding contract.** See [`STORY_BIBLE.md`](STORY_BIBLE.md) for the shape this book must never
> contradict.

## The register

One narrator, plain and funny, continuous with *Physics Won't Hurt You*. Enter every chapter through
a person and a scene, not a definition.

- **Concrete picture before symbol.** Every position — categorical imperatives, veils of ignorance,
  the hard problem — gets a plain physical or everyday analogy before the technical name appears.
- **The digression is a feature.** Keep it tight; never let it eat the chapter's spine.
- **People first, ideas second — but always both.**
- **Ethics chapters never hand the reader a verdict.** They hand the reader the sharpest version of
  each side's actual argument, and name plainly where professional philosophers still disagree.
- **Metaphysics chapters carry the same honesty marker as Physics Won't Hurt You's Part Five:**
  rough working consensus / live open question / minority-but-serious position — never blurred.
- **No borrowed sentences.** Nothing here is copied from Sandel, Goldstein, Blackburn, Parfit, or
  any other existing popular-philosophy writing.

## Machine-tell taboos

No "in conclusion." No essay-style summary sentences closing a scene. No stacking three hedges in a
row. Let a short, plain sentence land a big idea and then get out of the way.
