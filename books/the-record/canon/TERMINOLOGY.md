# Working Terminology — *THE RECORD*

> Appendix A of the bible. A consistent vocabulary for drafting. See `CRAFT.md` for the
> **words to police** table — the phrasings that must never appear unqualified.

| Term | Meaning |
|---|---|
| **Actualised record** | An event that occurred and therefore has irreversible physical consequences |
| **Record residue** | The distributed surviving consequences measurable in the present |
| **Record inversion** | Solving backward for the least past configuration compatible with present residue |
| **Anchor** | Matter/place/authenticated evidence used to constrain a historical query |
| **Uncertainty field** | Spatial and temporal display of supported, unsupported and multiply possible reconstruction |
| **The Rain** | Ghanaian operational name for raw incoming correlation data |
| **Witness Protocol** | Nairobi's provenance, quorum and reproducibility framework |
| **Temporal reference** | Antarctic calibration that locates a residue layer in time |
| **Lucid Offline** | Present-day-inspired local cite-or-refuse reasoning instrument |
| **Lucid Scientific** | Fictional expanded scientific graph and computation system |
| **Lucid World** | Fictional global causal graph combining verified records and live state |
| **Forward Cone** | Set of still-admissible futures with probabilities that decay over time |
| **The Seed** | Portable deterministic Lucid core and graph schema |
| **The Convergence** | Systemic loss of independent behaviour caused by common predictive optimisation |
| **Global discontinuity** | Lucid's cautious label for civilisation-scale coupled failure |
