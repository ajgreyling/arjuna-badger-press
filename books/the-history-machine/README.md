# The History Machine

Near-future novel (2038). A joint venture of the world's leading universities reads the 420 Code as
a **codec for reality** and builds a machine that reconstructs what actually happened — until the
Antarctic clock dates one event to long before it occurred.

> The universe is the archive. The 420 Code is the codec. The History Machine is the reader.

## Continuity

Sits three years after *Afrika 2035* and sixty-two before *AFRIKA 2100*. The 420 Code is already the
accepted unified frame; this is the book about the Code being **used** — by people who did not write
it and do not need its author's permission. **G and AJ stay offstage by lock** (C-06): G's published
position on record inversion is four words long — *structure is not permission* — and the
consortium has been arguing about it for two years.
