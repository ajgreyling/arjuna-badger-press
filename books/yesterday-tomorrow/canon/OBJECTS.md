# Objects — *YESTERDAY, TOMORROW*

> Physical objects keep abstract science embodied. The Anchor is retired with the historical case
> (`RETIRED_IDEAS.md`); what follows is the current set.

---

## THE FILE — the cold open's pre-announced record

The Antarctic station's own archive holds a signed, timestamped file describing a physical event
**before it happened**, with a countdown pointing at Accra.

| Property | Requirement |
|---|---|
| Visual identity | Utterly mundane. A queued job, a receipt, a line in a log with the wrong number in it |
| Scientific function | Establishes that forward computation happened *before anyone built it deliberately* |
| Emotional function | Sanna is alone with it for four months. It is the loneliest object in the book |
| **False belief** | Something is sending messages. Someone tampered. The clocks are wrong |
| **Truth** | The machine computed it, from constraints already decided |
| Climactic rhyme | The last object in the book is also a timestamped file (below) |

## THE SEED — the portable core

| Property | Requirement |
|---|---|
| Visual identity | Unremarkable storage module or rugged phone. Power is reproducibility, not spectacle |
| Technical function | Deterministic core plus compressed grammar; local data supplies the useful state |
| Political function | Makes central containment impossible; turns **ingestion** into the key resource |
| Ethical function | Sovereignty for a village and asymmetric advantage for a fund are the same architecture at different scales |
| **False belief** | Owning the Seed means owning prediction |
| **Truth** | Without trustworthy local records it produces shallow or dangerous certainty |

## THE ENCRYPTED FILE — 1.000000

The last object. Created by Lucid **before** the intervention, timestamped, containing one number.

- It must be established as *ordinary* long before it matters: the Court writes sealed
  pre-commitments routinely, as a falsifiability discipline. G insisted on the practice in Act I.
- **It is the Fool's, and this is never stated** (L-08b). No character says so. The evidence a
  rereader assembles: which member has least to say whenever the corridor is computed, and which one
  is silent for six hours in ch-39.
- Nobody may explain the implication aloud. One character opens it and the chapter ends.
- It is never opened twice, and there is no second file.

## Recurring objects

- **A cheap external hard drive labelled by hand** — raw failed experiments; worth more than the polished cluster.
- **G's frozen commit receipt, printed on paper** — low-tech proof that the number preceded the measurement. Rhymes with every timestamped thing in the book.
- **Antarctic ice-core ampoule** — deep time in the hand; revealed to be only calibration, *not memory in a bottle*.
- **A Nairobi hardware signing token** — treated as truth incarnate, later shown to prove sequence and nothing else.
- **A Technopark access card with old company logos under new stickers** — institutional layers in one object.
- **The forbidden-phrase jar** — money in it for anyone who says *enhance*. Full by Act II. Nobody empties it.
