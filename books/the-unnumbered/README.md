# The Unnumbered

**Piet Buys · Book One** — South African literary crime. Scaffold stage.

The house's **unfaithful** Sherlock, and the deliberate opposite of
[`../modern-sherlock/`](../modern-sherlock/) (*The Scarlet Thread*, canon-true, London). This one
keeps the observation engine and the two-hander and throws out everything else — including the
genre's favourite lie, that a mind like this comes without a bill.
