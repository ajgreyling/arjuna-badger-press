# Certificate photostats (The Loneliest People)

Source scans for *The File* / *What Became of Him*, plus print embeds for *The Photostats*
(`build/chapters/ch-52.md`).

- `PLATES.json` — chronological catalogue with human labels (school → adult → yearbook).
- `print/` — JPEG embeds used in EPUB/PDF (max edge ~1400, q80).
- Yearbook sources (unredacted, names visible, including **S. Harts**) live under
  `../yearbook/source/`; their print JPEGs under `../yearbook/print/`.

Do not put full ID numbers into running book *text* (ch-50 redacts trailing digits). Names on
yearbook plates may stay visible.
