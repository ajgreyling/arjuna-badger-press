# NARRATIVE_ENGINES — *Henry Sugar*

> **Companion to** [`PLANTS_AND_PAYOFFS.md`](PLANTS_AND_PAYOFFS.md). Names every **MacGuffin,

## I. One-line engines

| Craft term | *Henry Sugar* |
|---|---|
| **Premise / what if** | What if a bored rich cheat taught himself to see through playing cards — and the training changed him more than the winnings? |
| **Story spine** | A greedy idle man reads a nested account of impossible sight, does the boring years, wins hollow, and spends twenty years turning the gift outward. |
| **Controlling idea** | *The world is much larger than advertised; a gift misused can become a gift turned outward — but nothing satisfies if you can have as much as you want.* |
| **Dramatic question (Act I)** | Can Henry learn what Imhrat learned? |
| **Dramatic question (Act II)** | Will he use it only for greed — and pay the yogi code? |
| **Dramatic question (Act III)** | What is the money *for* once sight arrives? |
| **Blueprint** | Dahl matryoshka + Henry Sugar wonder engine + Break Good hyperbolic arc |

## II. Want vs. need

| | Content | Where it turns |
|---|---|---|
| **Want (conscious)** | See through cards · win at casino · more money without effort | Drives training + Lord's House |
| **Want (misbelief / lie)** | *Winning will satisfy me* · *Mild rebuke beats onerous task* | Hollow victory after £6,600 |
| **Need (unconscious)** | Enlargement · purpose · gift turned outward · (optional) love/witness (Max) | Money scramble → policeman → orphanages |
| **Granting the need** | Need met by **complicating** the want — money becomes burden, then pipeline | Charity arc; twenty-year grind |

**Rule:** Henry never states the need in diagnosis form. The policeman and the balcony show it.

## III. MacGuffin ledger

> **MacGuffin test (Hitchcock):** everyone chases it; the audience stops caring what it *is*; it
> exists to **move people through space and time**.

| ID | Object / goal | MacGuffin? | Role | Fate in story |
|---|---|---|---|---|
| **MG-001** | **Casino winnings** (£6,600 → £144m) | **YES (Act II)** | Drives greed loop; hollow prize | **Hollowed:** ceases to satisfy; becomes freight to Winston |
| **MG-002** | **Publish Khan / help the blind** (doctors' chase) | **YES (nest 2)** | Institutional chase | **Misfire:** Khan dies; science never gets him (PP-019–020) |
| **MG-003** | **Henry's true identity** (for world) | **Borderline** | Frame MacGuffin — everyone wants the "real name" | Protected; only pseudonym revealed |
| **MG-004** | **The blue exercise book** | **NO** | **Loading device + manual** — nature matters | Stolen; used; functional |
| **MG-005** | **Inner sight / two senses** | **NO** | **Functional engine** (like Relic gold — does what it claims) | Trains, fires, changes outlook |
| **MG-006** | **Playing cards** | **NO** | **Tool / Chekhov gun** (PP-001) — not interchangeable prop | Specific skill demonstration |
| **MG-007** | **Orphanages (as abstract goal)** | **NO** | **Moral destination** — specific institutions matter | 20+ built; ledger stated |
| **MG-008** | **Levitation witnessed (Banerjee)** | **NO** | **Proof seed** — convinces Imhrat/Henry that power is real | One scene; earns commitment |
| **MG-009** | **Alice text (nest 4)** | **NO** | **Method proof** — hand-as-sensor | Fires PP-027 |
| **MG-010** | **"Competent novelist's ending"** | **Meta-MacGuffin** | Side-shadow only — fake target ending | Denied (PP-051–052) |

### Press distinction (binding)

```
MACGUFFIN (hollow chase)     →  casino money · institutional publish
FUNCTIONAL ENGINE (not MG)   →  inner sight · blue book · cards · orphanage plan
LOADING DEVICE               →  nested document · frame commission
```

**Do not** treat inner sight as a briefcase the plot could swap for microfilm. The **card turn**
is the story's physics.

## XI. Quest-relay / key-chain

Not a relay adventure — but **nested documents** form a **knowledge key-chain**:

```
Blue book  →  Cartwright report  →  Imhrat tale  →  Alice proof  →  Henry practice  →  Card  →  Charity plan  →  Winston ledger  →  Author text
```

Each node **hands the next** a permission to believe or act. Break the chain = spine collapses.
