## Why this ledger exists

Roald Dahl's Henry Sugar is **fiction** built on **documented curiosity** (Kuda Bux; medical blindfold tests; yogi training tropes). This adult retelling adds a **second document tradition**: declassified remote viewing, presentiment meta-analyses, morphic/extended-mind arguments, and somatic meditation literature — the reading that made Henry's card turn feel **plausible after childhood**, especially **Joseph McMoneagle's *Mind Trek***.

## Tier 4b — René Peoc'h (chicks · REG · tychoscope — author origin)

> **Why this book cares:** The experiment that made "consciousness outside the skull" **visceral**
> for this author — before McMoneagle, before Radin meta-analyses. A **day-old chick** biasing a
> random robot toward its imprinted "mother."

| | |
|---|---|
| **Tag** | **DOCUMENTED** (experiments, papers) · **CONTESTED** (replication, methodology) |
| **Apparatus** | **Tychoscope** — small robot; path driven by **REG** (random event generator) |
| **Core finding (reported)** | Imprinted / motivated chicks associated with robot spending **~2.5×** longer near cage vs random; **~71%** of trials with groups of **15 chicks** showed excessive proximity to candle-bearing robot |
| **Controls** | No chicks, or non-imprinted chicks → random trajectories |
| **Human trials** | Peoc'h reported intention biasing robot path (same apparatus) |
| **Skeptic's best case** | Edge effects; protocol ambiguity; weak independent replication ([Psi Encyclopedia — Peoc'h](https://psi-encyclopedia.spr.ac.uk/articles/rene-peoch/)) |
| **In-fiction** | Backmatter / thematic origin only — **not** a new Henry power. Rhymes with Sheldrake (mind reaches) and Radin (RNG anomaly) |
| **Author inference (NOT one published trial)** | If one chick skews an REG, what of **12 or 144 trained meditators** focusing inner eye on one person's wellbeing? Thematic question; rhymes PEAR / GCP / group retreat literature — each contested |
| **Start here** | Peoc'h (1995) *JSE* 9/2; Peoc'h (2002) *Journal of Parapsychology* 66/3 · [Psi Encyclopedia](https://psi-encyclopedia.spr.ac.uk/articles/rene-peoch/) |

## Tier 6 — Consciousness as fundamental (philosophy & adjacent science)

> **Not owned by any single author above.** Useful context for readers who ask *why gospel?*

| Thread | Tag | One line |
|---|---|---|
| **Hard Problem** (Chalmers) | PHILOSOPHY | Subjective experience not fully explained by neural correlates alone |
| **Integrated Information Theory** (Tononi) | SCIENCE / CONTESTED | Consciousness tied to integrated information (Φ) |
| **Orch-OR** (Penrose & Hameroff) | CONTESTED | Quantum processes in microtubules — minority view |
| **Participatory universe** (Wheeler) | PHILOSOPHY | Observer participates in reality — often misquoted in pop culture |
| **Radin's framing** | ARGUMENT | Materialism vs consciousness-as-fundamental as **worldview choice** |

**Rule for this book:** We **dramatise** consciousness-first inside the fiction; we **tag** disputes here.
