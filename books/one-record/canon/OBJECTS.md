# MacGuffins & Object System — *THE RECORD*

> §9 of the bible. Physical objects keep abstract science embodied.

---

## Book I · **THE ANCHOR**

**Recommended form:** a damaged brass railway or municipal identity token fused to a fragment of
watch mechanism. Mundane, durable, locally plausible, visually distinctive — and conspicuously *not*
behaving like a magical storage device.

| Property | Requirement |
|---|---|
| Visual identity | Small, worn, tactile; recognisable in hand and in partial reconstruction |
| Scientific function | Constrains location, material interactions and event selection |
| Emotional function | Belongs to the disappeared person's family; makes the case personal |
| Political function | Who controls custody controls which query can be credibly run |
| **False belief** | Characters initially talk as if the object "contains" the event |
| **Truth** | The record is distributed; the Anchor is only **one address into it** |
| Climactic evolution | The team proves the event **without** it, preventing permanent monopoly through object ownership |

Design details that must survive drafting:

- It constrains location and material interaction; it does **not** contain imagery.
- Its official provenance contains a gap that initially makes the reconstruction inadmissible.
- Microscopic contamination links it to both the original site and a later evidence store.
- A duplicate-looking token creates a false-tampering avenue; tool marks later prove which is original.
- **The watch component stopped at a time that disagrees with the first Antarctic timestamp** — this plants the time-calibration mystery and is later resolved by layered material history, not by time loops.
- Its emotional owner is a **family**, not the consortium; custody therefore has moral and legal stakes.

## Book II · **THE SEED**

| Property | Requirement |
|---|---|
| Visual identity | Unremarkable storage module or rugged phone; power lies in reproducibility, not spectacle |
| Technical function | Deterministic core plus compressed graph schema; local data supplies the useful state |
| Political function | Makes central containment impossible and turns **ingestion** into the key resource |
| Ethical function | Sovereignty for a village and asymmetric power for a hedge fund are the same architecture at different scales |
| **False belief** | Owning the Seed means owning prediction |
| **Truth** | Without trustworthy local records it produces shallow or dangerous certainty |
| Climactic evolution | The universal join capability is destroyed; Seeds remain useful but cannot rebuild the global god-view alone |

## Supporting recurring objects

- **A cheap external hard drive labelled by hand** — contains raw failed experiments; becomes more valuable than the polished cluster.
- **G's frozen commit receipt printed on paper** — intentionally low-tech proof that the number preceded the later measurement.
- **Antarctic ice-core ampoule** — portable symbol of deep time, later revealed to be only calibration, *not memory in a bottle*.
- **A Nairobi hardware signing token** — initially treated as truth incarnate, later physically broken when authority is restructured.
- **A Technopark access card carrying old company logos beneath new stickers** — institutional layers embodied in one object.
- **The family's ordinary photograph of the disappeared person** — never used as machine input, protecting the distinction between memory and measurement.
