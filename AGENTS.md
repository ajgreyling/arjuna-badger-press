# Arjuna Badger Press — Agent Instructions

## What this repo is

The public library and static site generator for Arjuna Badger Press (`arjunabadger.press`).
Published book catalog, EPUB/PDF exports, cover art, and `site/build.py`.

Companion: `arjuna-badger-platform` — SaaS (Render), novel engine, Neon, R2, and
`saas/web/public/` (what Render serves at the custom domain).

Monorepo: `~/code/arjuna-badger/arjuna-badger-press` + `arjuna-badger-platform`.

## Infrastructure

| Layer | Role |
|---|---|
| Namecheap | DNS |
| Cloudflare | CDN in front of Render |
| **Render** | **Live site** at `arjunabadger.press` |
| Neon | Postgres (platform) |
| R2 | Workshop blobs only |
| GitHub Pages | CI mirror on `master` push — not custom-domain origin |

## Deploy (the most common task)

Read and follow **`arjuna-badger-platform/.claude/skills/deploy/SKILL.md`** end-to-end.

Summary:

```
0. (platform) ./tools/sync_library.sh     when prose changed in engine
1. python3 site/build.py
2. rsync site/public/ → ../arjuna-badger-platform/saas/web/public/
3. Verify downloads in platform saas/web/public/downloads/<id>/
4. Commit + push this repo (master)
5. Commit + push platform (main) — git add saas/web/public/ specifically
6. Render redeploy — RENDER_DEPLOY_HOOK_URL or Manual Deploy on Render
7. Verify curl https://arjunabadger.press/ shows the change
```

Never tell the user the book is live until step 6–7 succeed.

## Render LLM (platform)

Production SaaS uses **OpenRouter only** (`OPENROUTER_API_KEY` secret on Render). Do not set
`ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, or `PERPLEXITY_API_KEY` on Render. Full env list:
`arjuna-badger-platform/render.yaml` and `AGENTS.md` in the platform repo.

## Publishing a book

1. Sync from engine or add `books/<id>/build/export/`, `build/BOOK.md`, `design/cover.png` (> 500 KB)
2. Add `PUBLISHED` + `CURATED` in `site/build.py`
3. Run full deploy loop

## Key files

- `site/build.py` — `PUBLISHED`, `CURATED`, `SERIAL`, `WORKSHOP_HOLD`, `HIDE_BOOKS`
- `books/` — one directory per published book
- `.github/workflows/pages.yml` — GitHub Pages CI (parallel; Render is live origin)

## Never commit

- `site/public/` — generated by CI
- Secrets or `.env` files
