# Arjuna Badger Press — the library

> A free, open reading library. Every book here is free to **read online** or **download** as
> EPUB or PDF. No paywall, no account, no catch.
>
> *The archer's eye. The badger's nerve.* — [arjunabadger.press](https://arjunabadger.press)

This repository holds only **finished, published work** — the manuscripts, their covers, and their
EPUB/PDF downloads — plus the website that presents them. The autonomous manuscript engine
(StoryGraph · NovelBench · the editorial pipeline) and all canon, drafts, and tooling stay in a
separate **private** repository. The tools measure and sound the alarm; a human writes the soul of
the thing.
