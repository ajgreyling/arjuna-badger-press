# ChatGPT iOS handoff

Use this when continuing the Arjuna Badger Press work from ChatGPT on iOS.

## Current state

Arjuna Badger Press is a static generated site in `site/build.py`.

Build command:

```bash
python3 site/build.py
```

Generated output:

```text
site/public/
```

The public static site can stay on GitHub Pages to save money. Webdock should be used first for
dynamic services only:

- `arjunabadger.press` — GitHub Pages static site and PWA shell.
- `api.arjunabadger.press` — Webdock API for authoring chat, uploads, payments, print orders,
  royalties, narrator workflows, and app sync.
- Optional later: `files.arjunabadger.press` or object storage for large/private paid files.

## Recent site additions

New generated public pages:

- `narrators.html` — Arjuna Audio narrator intake.
- `distribution.html` — direct distribution, no bank gate for free books.
- `app.html` — app/PWA positioning.
- `reader.html` — local-first PWA reader shell.
- `authoring.html` — phone-first AI authoring.
- `audition.html` — DIY narrator audition guide.

The generated site is now installable as a PWA:

- `manifest.webmanifest`
- `sw.js`
- `favicon-512.png`
- PWA start URL: `/reader.html`

The current reader shell can:

- import local files without account or upload;
- render text, Markdown, and HTML;
- preview PDFs locally;
- play local audio files;
- acknowledge EPUB import as the next engine layer.

Still needed:

- real EPUB unpacking and chapter rendering;
- PDF text extraction and mobile reflow;
- persistent local library storage with IndexedDB;
- optional account sync through Webdock API;
- purchases, print orders, and royalty ledger.

## Webdock CLI

The Webdock CLI is installed locally.

The token was generated in the Webdock portal and initialized locally.

Verify from the normal terminal:

```bash
webdock account info
webdock servers list
```

The Codex sandbox could not resolve `api.webdock.io`, so live Webdock verification may need to be
done in the user's normal terminal.

## Deploy helper

A dry-run-first future migration helper exists:

```bash
scripts/deploy_static_webdock.sh
```

Default behavior is safe and uses `rsync --dry-run`.

Real deploy example:

```bash
ABP_DEPLOY_SERVER=your.webdock.host \
ABP_DEPLOY_DRY_RUN=0 \
ABP_REMOTE_RELOAD="sudo systemctl reload caddy" \
scripts/deploy_static_webdock.sh
```

Do not migrate off GitHub Pages until the Webdock copy is tested and DNS is ready to move.

## Product direction

Arjuna Badger Press is becoming a creator-owned publishing platform with these legs:

- free static library and PWA reader;
- phone-first AI authoring chat for authors;
- narrator marketplace for countries excluded by ACX;
- voice actor royalty floor: minimum 5% of net profit for at least 5 years;
- direct distribution without banking-detail gates for free books;
- paid rails later: M-Pesa, Mukuru, PayPal, card, and blockchain where useful;
- small-batch print ordering through idle print capacity.

## Next best engineering step

Build the real PWA reader engine in the least risky order:

1. Add IndexedDB persistence for imported local files and reading progress.
2. Add EPUB parsing in-browser using a ZIP parser.
3. Add chapter navigation and typography controls.
4. Add PDF text extraction and mobile reflow.
5. Add audiobook bookmarks, playback position, and chapter markers.
6. Add optional Webdock API only after the local-first reader works.
