# Source Study — *Stranger in a Strange Land* (Heinlein, 1961)

A craft/arc/theme ingestion of Heinlein's *Stranger in a Strange Land*, built the same way the
public-domain Sherlock canon was ingested for [`books/modern-sherlock`](../../../books/modern-sherlock) —
**read the master, distil the reusable engine, decide retelling-vs-original.**

> ⚖️ **Legal note up front.** *Stranger* is **in copyright** (Heinlein d. 1988 → protected ~until 2058),
> unlike the public-domain Holmes canon. **Studying the craft is 100% legal** (technique, structure,
> theme, and voice are not copyrightable). **Publishing a derivative is not** (needs a license from the
> Heinlein estate — Eleanor Wood / Spectrum Literary Agency). The retelling-vs-original decision turns
> entirely on this — see `00-DECISION-retelling-vs-original.md`. No protected prose is reproduced in any
> file here; only short illustrative fragments appear, marked as quotation, for craft study.

## Method note
The five part-level close reads were produced by dedicated reading agents over the full 1961
unabridged text (~215k words). The master craft bible and the original concept seeds were synthesized
via metered OpenAI (gpt-4.1) through the africangold engine client (off-subscription), cross-referenced
against the studio's `docs/craft/CRAFT_DOCTRINE.md` and house `STYLE_GUIDE.md`. The single highest-value
artifact is the **§10 Doctrine Cross-Walk** in `00-CRAFT-BIBLE.md`: it tells an Arjuna author exactly
which Heinlein moves to take and which faults to fix.
