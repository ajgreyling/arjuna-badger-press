# Literary and Vocabulary Sources for the Correction Corpus

Research for Arjuna Badger Press correction corpus (`docs/corpus/`). Target languages: **af**, **zu**, **xh**, **tn**, **st**, **sw**.

**Scope:** Link and document only. Do not bulk-download copyrighted works. Prefer clearly public domain (PD), CC0, CC-BY, or explicit open licenses. Flag uncertain copyright.

**Priority key:** **P1** = start here (large, clear license, good extraction). **P2** = strong supplement. **P3** = niche register or smaller yield.

**Temp suitability (corpus `temp_min` / `temp_max`):** Urban/garage register in existing JSON uses ~0.65–1.0. Biblical, missionary, and colonial-era literary sources suit **lower temp** (0.0–0.5). Modern open storybooks suit **mid temp** (0.5–0.75).

## Practical Ingestion Plan for `correction_corpus` JSON

Existing seed files (`sa_urban_*.json`) use entries like:

```json
{
  "id": "sa-af-001",
  "source_lang": "en",
  "lang": "af",
  "kind": "translate",
  "original": "Hello there",
  "fix": "Howzit",
  "temp_min": 0.65,
  "temp_max": 1.0,
  "weight": 100,
  "source_url": "https://…",
  "contributor": "Arjuna Badger Press corpus seed"
}
```

### 1. Extract vocabulary and phrase pairs

| Source type | Extraction approach | `kind` | Temp band |
|-------------|---------------------|--------|-----------|
| **Bilingual (Callaway, Steere, Pettman)** | Align Zulu/Xhosa/Swahili sentence with English column; sample phrase pairs where alignment is clean | `translate` | 0.0–0.5 |
| **Monolingual literary (Gutenberg, DBNL, Sekese)** | Tokenise; keep hapax/lemmatised nouns, verbs, idioms; optionally pair with human/LLM gloss **only if** you mark `contributor` and do not present as authoritative translation | `register` or new `vocab` | 0.0–0.4 literary; 0.5+ if colloquial glossary |
| **Wordnets / Wiktionary / Mafoko** | Import lemma → definition → EN equivalent as curated pairs | `translate` or `glossary` | 0.0–0.3 |
| **African Storybook** | Short dialogue lines; EN version often available on same story page | `translate` | 0.5–0.75 |
| **Urban seed (existing)** | Keep as high-weight anchor at temp 0.65–1.0 | `translate` | 0.65–1.0 |

**Pipeline sketch:**

1. Download **one PD title** at a time (PG `.txt.utf-8`, wiktextract JSONL, AWN XML).
2. Normalise Unicode (NFC), strip markup.
3. Sentence-segment (`.!?` + language-specific rules for agglutinative morphology).
4. Deduplicate by `(original, fix)` hash.
5. Assign `temp_min`/`temp_max` from register table above.
6. Set `weight` 10–30 for literary bulk, 100 for curated human-verified rows.
7. Append to `literary_<lang>.json` or merge into `sa_urban_<lang>.json` with distinct `id` prefix (`lit-zu-`, `bib-tn-`, etc.).

### 2. Chunk for Ollama RAG vs curated JSON

| Layer | Purpose | Chunk size | Storage |
|-------|---------|------------|---------|
| **RAG chunks** | Context for model at inference | 300–800 tokens, 50-token overlap | `docs/corpus/rag/<lang>/<source-id>.md` + embedding index |
| **Curated corrections** | Deterministic post-processing | Phrase-level (2–12 words) | `sa_urban_<lang>.json` / `literary_<lang>.json` |
| **Register metadata** | Temp gating | Tag each chunk: `literary`, `biblical`, `legal`, `children`, `urban` | YAML front matter on RAG files |

Do **not** embed full Bibles into correction JSON (too noisy). Use Bible for **RAG background** or frequency lists only, with `temp_max ≤ 0.35`.

### 3. Suggested build order

1. **af:** Gutenberg TXT + DBNL PD zip + Pettman *Africanderisms*
2. **sw:** Wikisource *Swahili Tales* + Steere handbook vocabulary
