# Craft Library — free resources for writers

> **Arjuna Badger Press · The Academy** — degree-level creative-writing craft, distilled from
> finishing a million words of published fiction and three independent professional editorial
> passes. Plain English. Named failure-modes. No MFA gatekeeping.

This library is **free and public** — the same body of knowledge the studio uses to finish books.
Read it whether or not you ever work with the press.

## Start here

| Guide | What it teaches |

## How to use it

1. **Drafting?** Read *Structure & Story* and *Character & Dialogue* in the Glossary — then the Doctrine's non-negotiables.
2. **Revising?** Run the *Pitfalls & Machine-Tells* checklist in the Glossary, then scan the Anti-Patterns catalog for habits above the sentence.
3. **Breaking rules on purpose?** Every "Rule" here is a default that needs a *reason* to violate. Earned violation is craft; accidental violation is error.

## What this is not

- Not a substitute for sensitivity readers, legal review, or fact-checking your own subject.
- Not the private canon, prompts, or engine tooling — those stay in the workshop.
- Not static — the studio updates these files as new books teach new lessons.
