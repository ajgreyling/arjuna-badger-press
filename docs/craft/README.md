## How to use it

1. **Drafting?** Open the [Glossary](CRAFT_GLOSSARY.md) — find the term (beat, scene, act, spine…), read the short definition, then open the full explainer.
2. **Revising?** Start with [**LLM tics & tells**](LLM_TELLS.md) (Not X/Y, em-dash, "the way…"), then the Glossary *Pitfalls* entries, then [Anti-Patterns](ANTI_PATTERNS.md).
3. **Breaking rules on purpose?** Every "Rule" here is a default that needs a *reason* to violate. Earned violation is craft; accidental violation is error.

## What this is not

- Not a substitute for sensitivity readers, legal review, or fact-checking your own subject.
- Not the private canon, prompts, or engine tooling — those stay in the workshop.
- Not static — the studio updates these files as new books teach new lessons.
